# 可复用地区节点组

2026-10-16 新增六组：🇭🇰 香港节点、🇨🇳 台湾节点、🇯🇵 日本节点、🇸🇬 新加坡节点、🇺🇲 美国节点、🌍 欧洲节点。当前共 20 个策略组。

例如在“💬 Ai平台”中选择“🇺🇲 美国节点”，再进入“🇺🇲 美国节点”选择美国 01/02。以后调整美国组的节点，所有引用它的业务组会一起采用新选择。

TG亚太默认新加坡组，TG北美默认美国组，TG欧洲默认欧洲组。TG目标IP的分类和规则顺序未变化。通用选择、AI、YouTube、谷歌、苹果、微软、漏网和 TG 兜底都可以直接选择六个地区组。

地区组为 select，组内手动切换节点，初次默认第一个匹配地区节点。每个地区组最后保留“♻️ 自动选择”：无该地区节点时不会出现空组，但此兜底会在全部订阅节点中自动选择，可能跨地区。地区组没有自动在同地区测速选优的行为；通用的“♻️ 自动选择”仍提供全局测速。无地区节点和节点连接失败是两种情况，select 不会因连接失败自动改变选择。

节点通过名称识别，需检查机场是否使用常见中文、英文、国家代码或旗帜。代码匹配有字母边界，避免 RUSSIA/AUS/JPG/TWO/HKT 被误认成美国、日本、台湾、香港。英国/德国/荷兰等共用欧洲组。MiSub/Subconverter 保持 sort=false，避免初始顺序被排序改变。

四套合成节点验证：中英文地区节点、仅香港、纯英文代码、误匹配反例；全部通过 Subconverter 0.9.0 转换与 Mihomo 1.19.32 配置检查。20 组均非空、引用有效无环，原 8722 条展开规则不变，IPv4/IPv6 和首次匹配断言通过。

使用时刷新 MiSub 转换结果并更新 OpenClash 订阅。如果仍显示旧组，清除转换缓存或给外部 INI 地址添加版本参数重新转换；OpenClash 已保存的业务选择可能继续沿用，需要手动选择一次新地区组。
