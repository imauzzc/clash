# 地区节点分组

当前保留五个地区节点组：香港、台湾、日本、新加坡、美国；另有一个专供 DNS 使用的 `🌐 DNS 出口` 组，不参与常规分流。

欧洲及其他地区节点不单独分组：`config/Home_Routing.ini` 没有为它们定义正则或策略组，这类节点只会出现在 `🚀 节点选择` 的候选里，需要时在该组内手动指定。Telegram 的欧洲规则同样已并入 `📲 TG兜底`，不再单独使用 TG 欧洲策略组。

每个地区组提供手动选择和同地区自动测速子组。自动测速只检查该地区候选节点，周期 300 秒、延迟容差 20 毫秒；没有匹配节点时保留 REJECT 占位，不跨地区兜底。更新订阅后请重新选择需要的地区或自动测速组。
